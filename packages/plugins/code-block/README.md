# @penline/code-block

Code block for penline: plain-text blocks with syntax highlighting.

> Pre-release (0.x): the API can still change between minor versions.

```sh
npm install @penline/code-block @penline/core
```

Entry points: `@penline/code-block`, `@penline/code-block/react`.

Part of [penline](https://github.com/DaoHuyTuan/headless-editor), a headless rich-text editor. See the [README](https://github.com/DaoHuyTuan/headless-editor#readme) for usage, and [docs/plugin-api.md](https://github.com/DaoHuyTuan/headless-editor/blob/main/docs/plugin-api.md) for the plugin API.
